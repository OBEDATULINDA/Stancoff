STANCOFF VERSION 7.5.4

PAYMENT PREVIEW FIX
- Fixed the browser error:
  Unexpected token '<', "<!doctype "... is not valid JSON
- Salary-advance calculation had been placed before the worker pay type and
  payment dates were defined, causing Flask to return an HTML 500 error page.
- Payment preview now validates worker and dates first, then calculates advances.
- The preview route now returns a JSON error message even if an unexpected
  backend calculation error occurs.

MONTHLY PAY PERIOD FIX
- Rolling monthly periods are counted correctly.
- Example: 05 Aug to 04 Sep is now ONE monthly salary period, not two simply
  because it crosses two calendar months.

DATABASE SAFETY
- No tables, records or PostgreSQL data are changed by this update.
