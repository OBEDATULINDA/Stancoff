STANCOFF / MOTHERS HARVEST UPDATE 7.1.3
========================================
Verified against the GitHub project ZIP uploaded on 2 Sep 2026.

Problem found
-------------
The live project contained the edit form templates, but the commercial list templates did not contain Actions columns and app.py did not contain the edit/delete routes. Therefore no buttons could appear for old or new records.

Fix
---
- Adds working Edit/Delete routes for Mothers Harvest Suppliers, Purchases, Drying, Analysis and Production.
- Adds a visible Actions column immediately after each record number/code.
- Edit is available to users with Commercial permission.
- Delete is visible to Admin only.
- Existing trial records receive the same buttons; this is not limited to records created after the update.
- Supplier codes remain system-generated and cannot be edited.
- Deletes are dependency-protected to protect stock and traceability.
- Production delete restores source stock and removes unused output lots.
- Purchase delete removes its unused source lot only when no downstream activity exists.

DATA SAFETY
-----------
No database tables are dropped or recreated. Existing Stancoff and Mothers Harvest records remain intact unless an Admin explicitly presses Delete on a permitted record.
